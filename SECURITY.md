# Security and private reports

The JQ API is operated by Craftsman Founder LLC and maintained by Lucas Carlson.
Send private security and privacy reports to **contact@thejqapi.com**.

Please describe how to reproduce an issue using public sample data. Do not post
credentials, private JSON, or customer data in public issues. This document does
not establish a bug bounty or a guaranteed response time.

The hosted implementation is private. This repository publishes documentation,
examples, and the external monitoring client. See the
[privacy notice](https://thejqapi.com/privacy) for data-handling details.
